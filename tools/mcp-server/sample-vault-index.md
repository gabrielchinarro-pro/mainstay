# Vault index

The navigable index of the knowledge vault. This is the file the
`vault://index` MCP resource serves. In a real monorepo it lives at
`vault/00-index.md` and links every artifact the agent may need. The paths
below are shown as code rather than links because this sample ships without
the surrounding vault tree.
